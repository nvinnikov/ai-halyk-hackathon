# Датасеты соревнования — материалы организатора

Оба каталога — пакеты задания Halyk AI Challenge, воспроизведённые **без
изменений**. Это не часть решения и не редактируется: конвейер обязан
разбирать их такими, какие они есть, включая подсадной мусор в `documents/`
(`Thumbs.db`, `~$lock.docx`, `.DS_Store`, лишние CSV и TXT).

| Каталог | Что внутри |
| --- | --- |
| `agentic-bank-public/` | Открытый набор: 12 сценариев, 200 PDF, 1473 проводки, `ground_truth.json` (ключ открыт). |
| `agentic-bank-private/` | Закрытый набор соревнования: 27 сценариев, 302 PDF, 2355 проводок. `ground_truth.json` нет — это и есть закрытый ключ. |

Архивы из этих каталогов собираются воспроизводимым упаковщиком
(`make public-archive` / `make private-archive`); сами `*.zip` в git не
хранятся. Целостность закрытого набора сверяется по sha256:
`make verify-private ARCHIVE=6a7819a8cb7d3480322468.zip`.
