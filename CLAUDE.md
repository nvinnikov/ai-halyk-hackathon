# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## О репозитории

Решение кейса Agentic Bank (Halyk AI Challenge). Из леджера за 2025 год
(`master_ledger_2025.csv`) и PDF-документов заёмщиков считаются финансовые
ковенанты (пункты 6.1 / 6.2 / 6.3 по каждому сценарию), результат — `out/submission.json`.

Приватный датасет открывается 9 августа 2026 в 11:00 (Астана), дедлайн 14:00 —
окно 3 часа. Отсюда все решения в коде: воспроизводимость, fail-open, отсутствие
хардкода под публичный набор.

Скоринг ячейки (`CASE.ru.md`, раздел 4): 0.50 за `status`, 0.30 за `actual`
(`0.30 × max(0, 1 − e/0.05)`, `e` — относительная погрешность), 0.20 за
`evidence_txn_id` (при `null` в ключе баллы убывают вместе с `actual`). Неверный
`status` обнуляет ячейку целиком. Максимум на публичном наборе — 36.00.

## Команды

```bash
./run.sh <архив.zip>   # единственная точка входа: архив → out/submission.json
make solve      # то же через make (ARCHIVE=... переопределяет архив)
make check      # локальное зеркало CI: lint + typecheck + test
make install    # uv sync --extra dev
```

Один тест: `uv run pytest tests/test_solution.py::test_deterministic`.

**Всё запускается из корня репозитория** — пути к датасету относительные
(`dataset/agentic-bank-public/...`). Окружение — `uv` из `uv.lock`, Python пинится
`.python-version` (3.12).

## Архитектура текущего решения

Поток: `master_ledger_2025.csv` + факты из документов → нормализованные строки →
метрика → вердикт → улика.

- **`engine.py`** — единственная точка чтения леджера. `load(scenario)` фильтрует
  строки, применяет факты досье (исключения периода, `amount_override`, FX,
  реклассификации) и категоризует по описанию. Возвращает `(rows, facts)`;
  дальше все агрегаты (`totals`, `revenue`, `inflow`, `related_payments`) считаются
  только по этому списку.
- **`categorize.py`** — правила регулярками по `description`, первое совпадение
  выигрывает. Категоризовать по контрагенту нельзя: имена контрагентов
  систематически не соответствуют сути операции.
- **`facts.py`** — `FACTS[scenario]`: связанные стороны, реклассификации,
  отсечения периода, курсы, добавки к EBITDA. Сейчас это размеченный вручную
  словарь; в целевом пайплайне его должен восстанавливать LLM-слой из PDF.
  Потребители читают ключи через `.get` с дефолтом — набор ключей у каждого
  сценария свой.
- **`covenants.py`** — `M` (реестр метрик через декоратор `@metric`), `SPECS`
  (`сценарий → пункт → (метрика, направление, порог[, опции])`) и `DRIVERS`
  (строки, формирующие ограничиваемую величину — нужны для поиска улики).
- **`solve.py`** — harness: `main(archive)` печатает `dataset_hash` первой строкой,
  кладёт на диск скелет submission из приора (`eval/prior.json`) сразу после чтения
  шаблона и перезаписывает его по одной посчитанной ячейке — на любой секунде
  прогона `out/submission.json` валиден. Сбой ячейки или загрузки сценария
  fail-open: печатается `ALARM`, ячейка остаётся фолбэком, прогон продолжается.
  Каждая ячейка пишет трейс `work/<hash>/trace/<сценарий>.<пункт>.json`
  (разбирать имя как `stem.split(".", 1)`). Вычислительное ядро — `solve_cell`,
  точка подмены для фаз 1–2; `score` печатает сверку с `ground_truth.json`.
- **`dossier.py`** — детерминированная маршрутизация документов (тип, `ACC-\d+`,
  отсев недействующих редакций). Пока не подключён к расчёту; переписывается в
  задаче 21 на постраничный текст из `pdftext.py`.

### Логика улики (`find_evidence`)

Улика возвращается только при `BREACH` и только когда операция определяет
вердикт единолично: либо ограничиваемый набор из `DRIVERS` состоит ровно из одной
строки, либо откат конкретного документального решения (реклассификация,
исключение, `amount_override`) переворачивает вердикт. Несколько кандидатов →
`None`, и это правильный ответ, а не пробел.

`_flips` временно подменяет `FACTS[scenario]` — глобальная мутация с
восстановлением в `finally`. Учитывать при любых правках вокруг.

## Конвенции и ловушки

- Модули `solution/*` делают `sys.path.insert(0, "solution")` и импортируют друг
  друга плоско — репозиторий не пакет (`[tool.uv] package = false`). Ruff-правило
  `E402` отключено именно поэтому. `tests/conftest.py` фиксирует и `cwd`, и `sys.path`.
- `dataset/agentic-bank-public/` — пакет от организаторов, **не редактируется**.
- Регрессионный порог скора — `BASELINE` в `tests/test_solution.py`. Улучшили
  решение — поднимите порог тем же коммитом, иначе откат назад не поймается.
- Форма ответа сверяется с `submission_template.json` (инвариант проверяется в
  `dump_submission` перед каждой записью); `main()` должен быть детерминирован
  (тест `test_deterministic`).
- Известные грабли, зафиксированные в спеке: `round()` — банковское округление
  (для `actual` нужен `Decimal.quantize(ROUND_HALF_UP)`); итерация по `set` и
  суммирование `float` в порядке словаря ломают воспроизводимость — сортировать
  перед использованием.
- Код, идентификаторы и логи — на английском; комментарии, докстринги и
  сообщения коммитов — на русском.

## Перестройка по спеке

Репозиторий перестраивается из подогнанного руками решения в самостоятельный
пайплайн:

- **Дизайн-спека:** `docs/superpowers/specs/2026-08-06-halyk-pipeline-design.md`
- **План реализации (31 задача):** `docs/superpowers/plans/2026-08-06-halyk-pipeline.md`

Ключевые инварианты, которые надо держать при любых правках:

- **«LLM читает, код считает».** Модель трогает только то, что требует понимания
  текста; её выход всегда проходит JSON-схему и грамматику до попадания в расчёт.
  Арифметику (EBITDA, проценты, доли) модель не делает никогда.
- **Детерминизм через content-addressed кэш**, а не через `temperature=0`. Ключ =
  `sha256(model_id + prompt + json_schema + schema_version)`. Кэш не
  инвалидируется по времени, только по содержимому; «заморозка» — это снимок
  каталога кэша рядом с отправляемым JSON, а не запрет на правки.
- **Греп-гейт:** ни одного имени заёмщика, номера пункта (`6.1`), порогового
  числа, префикса `TXN-`/`ACC-` в `solution/` — только в `tests/` и `eval/`.
  Ничего не зашивать под 3 пункта на заёмщика, 12 сценариев, `USD`/`EUR`,
  русский язык, `ACC-\d{4}`.
- `facts.py` и `SPECS` уезжают в `eval/expected_extraction.py` как эталон для
  измерения LLM-слоя и перестают быть входом в пайплайн.

Раздел 4.1 спеки перечисляет известные дефекты `engine.py`, которые чинятся по
плану (молчаливый FX=1.0, незащищённый `float()` на `amount`, маршрутизация по
`txn_id.split`, двусторонний подстрочный матч связанных сторон).
